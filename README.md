# E-commerce Customer Retention Analysis

## Project Overview

This project analyses customer purchasing behaviour and retention using the Brazilian Olist e-commerce dataset. The goal is to understand customer behaviour, identify factors associated with customer churn, and explore how data analysis and machine learning can support business decisions.

## Dataset

Project uses Brazilian E-Commerce Public Dataset by Olist, which contains information about customer orders, purchases, products, payments, and customer reviews.

## Methods and Techniques

- **Data Cleaning and Preprocessing:** Preparing and combining datasets for analysis.
- **Exploratory Data Analysis (EDA):** Examining purchasing patterns and customer behaviour.
- **Customer Retention Analysis:** Investigating repeat purchases and customer churn.
- **Predictive Modelling:** Using Random Forest to predict customer churn.
- **Model Evaluation:** Using train/test splitting, K-fold cross-validation, accuracy, precision, recall, and F1-score.
- **Feature Importance:** Identifying factors associated with customer churn.

## Tools and Technologies

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook / Google Colab

## Project Outcome

The project combines business intelligence and machine learning to explore customer retention in e-commerce. It demonstrates how transactional data can be used to understand customer behaviour, evaluate churn risk, and support data-driven business decisions.

## Project Type

Academic group project — Business Intelligence, Data Analytics, and Machine Learning.
